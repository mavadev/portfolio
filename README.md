# Portafolio “Próximamente” — Astro + Tailwind CSS

Página temporal, responsive y lista para desplegar mientras construyes el portafolio completo.

## Tecnologías

- Astro 7
- Tailwind CSS 4 mediante `@tailwindcss/vite`
- TypeScript integrado en Astro
- JavaScript nativo dentro de componentes `.astro`
- Sin React ni dependencias de iconos

## Instala y ejecuta

```bash
npm install
npm run dev
```

Abre la dirección que muestre la terminal, normalmente `http://localhost:4321`.
